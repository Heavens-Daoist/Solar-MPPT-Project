# PV Modelling

This directory contains the photovoltaic modelling work for the Solar Energy
Harvesting System + MPPT project.

## Objectives

- Build a photovoltaic module model
- Implement the single-diode equivalent circuit
- Generate I-V and P-V characteristics
- Validate the model against a commercial module datasheet
- Study irradiance and temperature effects
- Provide a reusable PV model for the MPPT simulation
