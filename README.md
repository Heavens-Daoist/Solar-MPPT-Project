#  Solar Energy Harvesting + MPPT

An end-to-end project exploring **solar PV energy harvesting and Maximum Power Point Tracking (MPPT)** , from solar-cell physics and mathematical modelling to Python simulation, MPPT algorithms, embedded C, and hardware.

###  Goals

* Understand **how and why solar cells work**.
* Build and validate a **single-diode PV model** in Python.
* Study how irradiance and temperature affect the **Maximum Power Point (MPP)**.
* Implement and compare **P&O and Incremental Conductance MPPT**.
* Understand and build the **buck converter** used to control the PV operating point.
* Deploy the selected MPPT algorithm on a **microcontroller using embedded C**.
* Test the system on hardware and compare **theoretical, simulated, datasheet, and measured results**.
* Document everything professionally and be able to **explain the entire system from first principles**.

**Core engineering chain:**
`PHYSICS → MODEL → SIMULATION → MPPT → FIRMWARE → HARDWARE → MEASUREMENT → VALIDATION`

The project follows the original Project C concept of taking solar modelling through MPPT and ultimately into embedded hardware.
